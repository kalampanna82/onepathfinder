# OnePathFinder brand kit

The mark is a "Checkpoint": a checkmark that runs into a map pin. It says "done right, and pointing the way" for tax and immigration paperwork. It uses the same obsidian and gold palette as PentoGIS.

## Files

| File | Use |
|---|---|
| `svg/onepathfinder-logo-light.svg` | Primary horizontal logo on light backgrounds (the website header) |
| `svg/onepathfinder-logo-dark.svg` | Primary horizontal logo on dark backgrounds |
| `svg/onepathfinder-logo-nav-light.svg`, `svg/onepathfinder-logo-nav-dark.svg` | Compact logo without the tagline, for website headers and anything under about 200 px wide |
| `svg/onepathfinder-icon-light.svg`, `svg/onepathfinder-icon-dark.svg` | Icon only |
| `svg/onepathfinder-logo-mono-black.svg`, `svg/onepathfinder-logo-mono-white.svg` | One-colour logo for print, stamps, fax, watermarks |
| `svg/onepathfinder-icon-mono-black.svg`, `svg/onepathfinder-icon-mono-white.svg` | One-colour icon |
| `svg/favicon.svg` | Browser tab icon |
| `png/favicon-16.png` to `favicon-512.png` | Fallback favicons, Apple touch icon (180), Android and PWA icons (192, 512) |
| `png/onepathfinder-social-avatar-1024.png` | Profile picture for LinkedIn, X, Facebook, Google Business |
| `png/onepathfinder-og-banner-1200x630.png` | Link preview image |
| `png/*` (logo and icon) | Ready-made PNGs for slides, Word and email signatures |

All wordmark lettering in the SVG files is converted to outlines, so the logos look the same everywhere with no font installed. The same files that the site uses (`logo-nav.svg`, `logo-dark.svg`, `logo.svg`, `favicon.*`, `og-image.png`) live in the repo root and were regenerated from this kit.

## Colours

| Name | Hex | Use |
|---|---|---|
| Obsidian | `#0b0f14` | Dark backgrounds, text on light |
| Champagne gold | `#d4b06a` | Accent on dark |
| Deep gold | `#a8843f` | Accent on light (graphics); use `#8a6a2b` for small text |
| Off-white | `#e8e6df` | Text on dark |
| Steel | `#566b86`, `#7f93ad` | Short stroke of the check |
| Slate | `#6f7681`, `#8a8f98` | Tagline and small text |

## Typography

Inter (free, Google Fonts). Wordmark: Inter Medium, all caps, letter-spacing 0.16em. Tagline: Inter Regular, all caps, tracked to match the wordmark width.

## Rules

- Clear space: keep at least the width of the pin's head free on every side.
- Minimum size: icon 16 px, full logo 140 px wide. Below that, use the icon alone.
- Use the light logo on light backgrounds and the dark logo on dark ones. On photos or busy backgrounds, use the mono white or mono black.
- Don't stretch, rotate, recolour, add shadows, or move the pin.
- The tagline can be dropped for very small uses, but don't change its wording without updating the SVG.
